Factor Analysis

 📊 Project Overview

This project applies Factor Analysis using Python to identify underlying factors that explain the relationships among multiple observed variables.

Factor Analysis is a dimensionality-reduction technique that helps group related variables into a smaller number of meaningful latent factors.

🎯 Objectives

- Understand the structure of the dataset
- Examine relationships between variables
- Determine whether the dataset is suitable for Factor Analysis
- Identify underlying factors among the observed variables
- Reduce multiple variables into meaningful factor groups
- Interpret the extracted factors

 🛠️ Tools & Technologies

- Python
- Pandas – Data manipulation
- NumPy – Numerical computation
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Scikit-learn – Factor Analysis
- Google Colab 
  
🔍 Analysis Process

The project follows a structured Factor Analysis workflow:

1. Data loading and inspection
2. Data preprocessing
3. Selection of relevant variables
4. Correlation analysis
5. **Kaiser-Meyer-Olkin (KMO) test**
6. **Bartlett's Test of Sphericity**
7. Determination of the number of factors
8. Factor extraction
9. Analysis of factor loadings
10. Interpretation of the extracted factors

 📈 Factor Analysis

Factor Analysis was performed to identify groups of variables that share common underlying characteristics.

The **KMO test** and **Bartlett's Test of Sphericity** were used to assess whether the data was appropriate for factor analysis.

The extracted factors were then examined using factor loadings to understand which observed variables contributed strongly to each factor.
